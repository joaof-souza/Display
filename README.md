# 🎨 Estudo da Propriedade Display no CSS

Um projeto prático desenvolvido para compreender, visualizar e testar o comportamento dos diferentes valores da propriedade **`display`** em CSS, essencial para o layout e estruturação de páginas web.

---

## 🚀 Sobre o Projeto

Este repositório serve como um laboratório de estudos para entender como os elementos HTML se comportam no navegador. Através de exemplos visuais e práticos, o projeto explora as principais variações da propriedade `display`, demonstrando suas diferenças na prática.

### Conceitos Abordados:
* **`none`**: Oculta completamente o elemento da página (ele não ocupa espaço).
* **`block`**: Ocupa toda a largura disponível e quebra a linha antes e depois.
* **`inline`**: Ocupa apenas o espaço necessário pelo seu conteúdo e não quebra linha.
* **`inline-block`**: Permite definir larguras e alturas como um bloco, mas mantém o comportamento de linha (inline).
* **`flex`**: Ativa o **Flexbox**, um modelo de layout unidimensional poderoso para distribuição de espaço e alinhamento de itens.
